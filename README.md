# BloomEconomy News Bot

منصة مؤتمتة لنشر الأخبار الاقتصادية باللغة العربية: تراقب خلاصات RSS اقتصادية
عالمية، تعيد صياغتها وترجمتها وتصنيفها بأسلوب صحفي عبر OpenAI، ثم تنشرها في
**موقع إخباري خاص بها** يُبنى تلقائياً ويُستضاف مجاناً عبر GitHub Pages —
**بدون الحاجة لووردبريس أو أي استضافة مدفوعة**. يدعم أيضاً النشر الإضافي
الاختياري إلى ووردبريس وتليجرام، مع تجنّب الأخبار المتكررة، وإشعارك فوراً
عند أي فشل.

## المزايا

- **موقع إخباري ساكن مجاني بالكامل**: يُبنى ويُنشر تلقائياً عبر GitHub Pages
  دون أي حساب استضافة أو ووردبريس. تصميم عربي (RTL) نظيف بصفحة رئيسية،
  صفحات تصنيفات، وصفحة لكل مقال.
- مراقبة عدة مصادر RSS في آن واحد (قابلة للتخصيص من `feeds.json`).
- إعادة صياغة وترجمة احترافية إلى العربية الفصحى بأسلوب الهرم المقلوب.
- **تصنيف تلقائي بالذكاء الاصطناعي**: كل خبر يُصنَّف ضمن فئة من `categories.json`
  (أسواق، نفط وطاقة، عملات رقمية، شركات، سياسات نقدية...).
- **منع التكرار والتشابه**: يكتشف الأخبار التي تتحدث عن نفس الحدث بصياغة
  مختلفة من مصادر متعددة ويتخطاها.
- **نشر إلى ووردبريس (اختياري)**: لمن يملك موقع ووردبريس ويريد النشر فيه أيضاً.
- **نشر إلى تليجرام (اختياري)**: يرسل نفس المحتوى إلى قناة أو مجموعة تليجرام.
- **إشعارات فورية عند الفشل** عبر تليجرام.
- **دعم منصة X مُجهّز مسبقاً** (معطّل افتراضياً حتى تكون جاهزاً لتفعيله).
- وضعان للتشغيل: حلقة مستمرة، أو تنفيذ دورة واحدة (`--once`) مناسبة للجدولة.
- **رفع تلقائي للموقع المحدَّث إلى GitHub** بعد كل دورة نشر (عبر `run_once.sh`).
- جميع البيانات الحساسة تُقرأ من `.env` ولا تُكتب داخل الكود مطلقاً.

## المتطلبات

- Python 3.9 أو أحدث.
- مفتاح OpenAI API فعّال (المتطلب الوحيد الإلزامي).
- حساب GitHub (مجاني) لاستضافة الموقع عبر GitHub Pages.
- (اختياري) موقع ووردبريس، و/أو بوت تليجرام عبر [@BotFather](https://t.me/BotFather).

## التثبيت

```bash
git clone https://github.com/z6666c/bloom-economy-news-bot.git
cd bloom-economy-news-bot
python3 -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## الإعداد السريع (3 أوامر فقط)

```bash
bash setup_env.sh       # يبني .env تفاعلياً (مفتاح OpenAI، اسم الموقع، خيارات إضافية)
bash finish_setup.sh    # يرفع المشروع لـ GitHub ويُفعّل الموقع مجاناً عبر GitHub Pages
python3 news_bot.py --once   # تجربة أولى — ينشر أول دفعة أخبار على الموقع
bash install_schedule.sh     # يُشغّل البوت تلقائياً كل 30 دقيقة (ويرفع التحديثات بنفسه)
```

بعد `finish_setup.sh` سيظهر لك رابطان: رابط المستودع، ورابط الموقع المباشر
(بصيغة `https://<اسم-حسابك>.github.io/bloom-economy-news-bot/`) — قد يستغرق
ظهور الموقع لأول مرة بضع دقائق بعد التفعيل.

### شرح الإعدادات (اختياري — لمن يريد التخصيص اليدوي)

| المتغير | الوصف |
|---|---|
| `OPENAI_API_KEY` | مفتاح OpenAI API (إلزامي) |
| `OPENAI_MODEL` | اسم النموذج (افتراضياً `gpt-4o-mini`) |
| `ENABLE_STATIC_SITE` / `SITE_TITLE` / `SITE_BASE_URL` | الموقع الإخباري (مفعّل افتراضياً) |
| `ENABLE_WORDPRESS` وبياناته | نشر إضافي في ووردبريس إن رغبت (معطّل افتراضياً) |
| `POST_STATUS` | `publish` أو `draft` (لووردبريس فقط) |
| `POLL_INTERVAL_MINUTES` | الفاصل الزمني بين الدورات في وضع التشغيل المستمر |
| `DUPLICATE_SIMILARITY_THRESHOLD` / `DUPLICATE_WINDOW_HOURS` | إعدادات منع التكرار |
| `ENABLE_TELEGRAM` وبياناته | النشر إلى تليجرام |
| `ENABLE_NOTIFICATIONS` / `TELEGRAM_ADMIN_CHAT_ID` | إشعارات الفشل |
| `ENABLE_X` وبياناته | مجهّزة لتفعيل النشر على X لاحقاً |

حدّث مصادر الأخبار في `feeds.json`، وحدّث أسماء التصنيفات في `categories.json`
حسب رغبتك (معرّفات `wp_category_id` فيه تُستخدم فقط إن فعّلت ووردبريس).

## التشغيل التلقائي بدون الحاجة لإبقاء جهازك مُشغَّلاً (GitHub Actions)

بالإضافة إلى الجدولة المحلية عبر `install_schedule.sh` (تحتاج جهازك مُشغَّلاً)،
يمكن تشغيل البوت مجاناً بالكامل على خوادم GitHub نفسها كل 15 دقيقة عبر
GitHub Actions — يعمل حتى لو كان جهازك مُطفأً تماماً.

```bash
bash setup_github_actions.sh ghp_xxxxxxxxxxxx
```

يقوم هذا السكربت تلقائياً بـ: رفع ملف الجدولة `.github/workflows/news-bot.yml`،
إضافة مفتاح OpenAI كـ Secret سري في إعدادات المستودع، ثم تشغيل أول تجربة
فورية. التوكن المستخدم يجب أن يملك صلاحيتي `repo` و `workflow` معاً (أنشئه من
https://github.com/settings/tokens إن لم يكن لديك توكن بهما).

تابع نتائج التشغيل من تبويب Actions في مستودعك على GitHub. إن فعّلت هذه
الطريقة، يُفضّل إيقاف الجدولة المحلية لتفادي التعارض أو النشر المزدوج:

```bash
launchctl unload ~/Library/LaunchAgents/com.bloomeconomy.newsbot.plist
```

## تحديث الموقع فوراً بعد تعديل التصميم

إذا عدّلت تصميم `site_generator.py` وتريد رؤية النتيجة فوراً على كل الأخبار
المنشورة مسبقاً (بدل انتظار خبر جديد):

```bash
bash rebuild_and_push.sh
```

### تفعيل النشر على منصة X (لاحقاً)

الدعم مُجهّز في الكود لكنه **معطّل افتراضياً**. عند جاهزيتك: أنشئ تطبيق مطوّر
على [developer.x.com](https://developer.x.com)، ثبّت المكتبة `pip install tweepy`،
ثم في `.env` ضع `ENABLE_X=true` وعبّئ المفاتيح الأربعة. لا حاجة لأي تعديل كود.

```
├── requirements.txt
├── .env.example
├── setup_env.sh            # بناء .env تفاعلياً
├── finish_setup.sh         # رفع المشروع + تفعيل GitHub Pages (خطوة واحدة)
├── push_update.sh          # رفع تحديثات لاحقة بسيطة (بديل أخف من finish_setup.sh)
├── setup_github.sh         # (تاريخي) إنشاء المستودع الأول — finish_setup.sh يكفي الآن
├── run_once.sh             # تشغيل دورة واحدة + رفع تلقائي للموقع (للجدولة)
├── install_schedule.sh     # تثبيت جدولة launchd على macOS كل 30 دقيقة
├── com.bloomeconomy.newsbot.plist
└── .gitignore
```

## ملاحظات أمنية

- لا ترفع ملف `.env` إلى GitHub أبداً — مستثنى مسبقاً في `.gitignore`.
- استخدم "Application Password" في ووردبريس بدل كلمة المرور الرئيسية إن فعّلته.
- عامل توكن GitHub وتليجرام ومفاتيح X كأي كلمة سر — لا تشاركها ولا ترفعها،
  وألغِ أي توكن GitHub استخدمته بمجرد انتهاء `finish_setup.sh` بنجاح.
