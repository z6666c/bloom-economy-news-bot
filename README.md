# BloomEconomy News Bot

منصة مؤتمتة لنشر الأخبار الاقتصادية باللغة العربية: تراقب خلاصات RSS اقتصادية
عالمية، تعيد صياغتها وترجمتها بأسلوب صحفي عبر OpenAI، ثم تنشرها تلقائياً
كمقالات في موقع ووردبريس عبر REST API الخاص به.

## المزايا

- مراقبة عدة مصادر RSS في آن واحد (قابلة للتخصيص من `feeds.json`).
- إعادة صياغة وترجمة احترافية إلى العربية الفصحى بأسلوب الهرم المقلوب.
- إخراج JSON منظم من نموذج الذكاء الاصطناعي لضمان اتساق العنوان والمحتوى.
- صندوق توثيق مصدر تلقائي في نهاية كل مقال مع رابط الخبر الأصلي.
- سجل داخلي (`published_history.json`) لمنع نشر نفس الخبر أكثر من مرة.
- وضعان للتشغيل: حلقة مستمرة، أو تنفيذ دورة واحدة (`--once`) مناسبة للجدولة
  عبر cron أو أي مجدول مهام.
- جميع البيانات الحساسة (مفاتيح API، كلمات المرور) تُقرأ من ملف `.env` ولا
  تُكتب داخل الكود مطلقاً.

## المتطلبات

- Python 3.9 أو أحدث.
- مفتاح OpenAI API فعّال.
- موقع ووردبريس مع كلمة مرور تطبيق (Application Password) لمستخدم لديه صلاحية النشر.

## التثبيت

```bash
git clone https://github.com/<your-username>/bloom-economy-news-bot.git
cd bloom-economy-news-bot
python3 -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## الإعداد

1. انسخ ملف الإعدادات النموذجي:

   ```bash
   cp .env.example .env
   ```

2. افتح `.env` وعبّئ القيم التالية:

   | المتغير | الوصف |
   |---|---|
   | `OPENAI_API_KEY` | مفتاح OpenAI API |
   | `OPENAI_MODEL` | اسم النموذج (افتراضياً `gpt-4o-mini`) |
   | `WP_BASE_URL` | رابط موقع ووردبريس بدون شرطة مائلة أخيرة |
   | `WP_USERNAME` | اسم مستخدم ووردبريس |
   | `WP_APP_PASSWORD` | كلمة مرور التطبيق (وليست كلمة مرور الحساب العادية) |
   | `POST_STATUS` | `publish` للنشر المباشر أو `draft` للمراجعة قبل النشر |
   | `POLL_INTERVAL_MINUTES` | الفاصل الزمني بين الدورات في وضع التشغيل المستمر |

3. حدّث مصادر الأخبار في `feeds.json` حسب الحاجة — كل مصدر يحتاج `name`،
   `url` (رابط خلاصة RSS)، و`category_id` (معرّف التصنيف في ووردبريس).

## التشغيل

تشغيل مستمر (يفحص وينشر كل `POLL_INTERVAL_MINUTES` دقيقة):

```bash
python news_bot.py
```

تنفيذ دورة فحص ونشر واحدة فقط ثم الخروج — الخيار الأنسب للتشغيل عبر مجدول
مهام (cron، Task Scheduler، إلخ):

```bash
python news_bot.py --once
```

## بنية المشروع


## ملاحظات أمنية

- لا ترفع ملف `.env` إلى GitHub أبداً — هو مستثنى مسبقاً في `.gitignore`.
- استخدم دائماً "Application Password" في ووردبريس بدل كلمة مرور الحساب
  الرئيسية، ويمكن إلغاؤها بسهولة من لوحة التحكم عند الحاجة.
